# Smart Cucine

Sito di **Smart Cucine F.lli Erba s.a.s.** — Via Garibaldi 219, 22073 Fino Mornasco (CO).

Sito statico: nessun CMS, nessun database, nessun plugin da aggiornare.

## Struttura

- 21 pagine HTML + negozio (`negozio.html`, `prodotto.html`, `carrello.html`)
- `gestione.html` — pannello di gestione del catalogo, fuori dal menu
- `catalogo.js` — i prodotti pubblicati
- `immagini/` — 172 immagini in formato WebP

## Manutenzione

Istruzioni complete in `LEGGIMI.txt`.

Per pubblicare gli aggiornamenti: doppio clic su `pubblica.bat`.
